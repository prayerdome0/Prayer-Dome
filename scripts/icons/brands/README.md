# Brand marks

Third-party logos from [Simple Icons](https://simpleicons.org) v16.32.0
(CC0-1.0, public domain). Lucide deliberately ships no brand logos, and these marks must
look like the real logos, so they are the only glyphs that do not come from Lucide or
`../custom/`. They are used only for share buttons, social links and "Sign in with
Google", and are exposed as `pd-i-brand-<name>`.

Do not add general UI icons here. UI icons come from Lucide.
